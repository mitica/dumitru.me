12:T85a,<p>Ournet este un portal web format din mai multe proiecte: știri, meteo, horoscop.</p>
<p>Proiectul pare destul de tipic, dar eu cred că este diferit și interesant. Fiecare parte a portalului este proiect individual interesant.</p>
<p>Portalul a pornit din R. Moldova (<a href="http://www.click.md">www.click.md</a>) și a fost &#39;exportat&#39; în alte țări.</p>
<h2>Țări</h2>
<p>Portal complet (știri, meteo, horoscop):</p>
<ul>
<li>Republica Moldova — <a href="https://www.click.md">click.md</a> (română și rusă);</li>
<li>România — <a href="https://www.ournet.ro">ournet.ro</a>;</li>
<li>Italia — <a href="https://www.ournet.it">ournet.it</a>;</li>
<li>Ungaria — <a href="https://www.ournet.hu">ournet.hu</a>;</li>
<li>Bulgaria — <a href="https://www.our.bg">our.bg</a>.</li>
</ul>
<p>Doar meteo:</p>
<ul>
<li>Albania — <a href="https://www.moti2.al">moti2.al</a>;</li>
<li>Turcia — <a href="https://www.hava.one">hava.one</a>;</li>
<li>Vietnam — <a href="https://www.thoi.vn">thoi.vn</a>.</li>
</ul>
<p>Restul țărilor (Spania, India, Cehia și alte site-uri meteo) au fost închise.</p>
